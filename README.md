# YOLO 训练平台

本地单机版 YOLO 训练平台：数据集管理 + 在线标注 + 训练监控 + 模型仓库 + 推理测试，全部在浏览器里完成。
基于 **FastAPI + Ultralytics (YOLO11/YOLOv8) + 原生 JS 单页前端**，无需 Node.js、无外部数据库。

## 快速开始

```bat
:: 首次：安装依赖并启动
install_and_run.bat

:: 之后：直接启动
run.bat
```

打开浏览器访问 **http://127.0.0.1:8750**

> 想局域网内其他设备访问：`python -m app.server --public`，然后用手机/其他电脑访问本机 IP:8750。

**第一次使用**建议直接点总览页的「⚡ 生成演示数据集并训练」，约 2 分钟跑通完整流程（平台会自动合成一批彩色几何形状图片）。

## 最常用的流程：客户只给图片

平台的主线用法——**客户不需要懂 YOLO、也不需要提供标注文件**：

1. **数据集页 → 「① 上传图片 → 生成数据集」**
   - 填数据集名称（类别可以先留空，标注时再补）
   - 把图片直接拖进上传区（JPG/PNG/WEBP/BMP/TIFF/HEIC 均可）
   - 点「开始导入并建数据集」，平台自动分批上传
2. **平台自动完成的后处理**（无需人工干预）
   - 手机照片 EXIF 旋转纠正，统一转为 JPEG
   - 超大原图按最长边 1920 压缩（标注/训练都用不到更大分辨率）
   - **重复图片自动去重**（感知哈希，重新压缩或缩放过副本也能识别）
   - 损坏/非图片文件自动跳过并列明原因
   - 按比例自动划分 train / val
3. **在线标注页** → 画框
   - 顶部实时进度条：已标注 X / 总数、剩余多少张
   - 默认**翻页自动保存**，不会因忘记点保存丢标注
   - 标完点「✅ 标注完成，去训练」
4. **训练任务页** → 选模型开训（标注过的数据集自动出现在下拉框）

> 后续补图：数据集卡片点「＋加图」，或直接把图片拖进标注页的画布区域。

## 数据格式约定

- 标注为 YOLO txt：`class cx cy w h`（归一化 0-1），与图片同名放在 `labels/<split>/`。
- **多形状标注**（矩形/圆/椭圆/多边形）：原始形状保存在边车文件 `labels/<split>/<图名>.shapes.json`，
  txt 只是训练投影——detect 任务存外接框，segment 任务存多边形点列（圆/椭圆采样 36 点）。
  二次打开时按 json 还原真实形状，不会丢类型；纯矩形标注不产生 json，目录保持干净。
  旧数据集（只有 txt）自动兼容；导出 zip 会带上 json。
- **纯图片导入（主流程）**：平台把上传图片规范化成 JPEG 存入 `images/train`，标注由客户在线完成。
- zip 导入兼容三种结构：
  1. 标准 YOLO 数据集（`images/train + labels/train + data.yaml`）→ 原样导入；
  2. 纯图片 zip → 全部进 train 并按比例自动划分，去标注页画框；
  3. 按类别文件夹组织的图片（`train/cat/xx.jpg`）→ 文件夹名作为类别。

### 去重机制

导入时对每张图算三类哈希并存索引（`data/datasets/<id>/_image_hashes.json`）：

| 哈希 | 作用 |
|---|---|
| SHA-1 | 完全相同文件秒判重 |
| dHash 16×16（256 位） | 识别重新压缩/缩放过的同一张图（相似度阈值 0.97） |
| aHash 16×16 | 二次校验，避免误删“相似但不同”的图 |

实测：同图重压缩相似度 1.000 会被去掉；同一底图但新增物体的图相似度约 0.941，会保留。

## 模型仓库

模型仓库是平台的「唯一模型入口」——训练和推理都从这里取模型。

### 三个来源

| 来源 | 怎么进来 | 说明 |
|---|---|---|
| 训练产出 | 训练完成后自动 | `best.pt` 自动登记，带 mAP 指标、类别、任务类型 |
| 本机导入 | 模型页「① 从本机添加模型」 | 填路径或点「浏览本机」选文件；自动识别任务/类别/参数量 |
| 预训练 | 模型页下载按钮 | yolo11n/s/m、yolov8n |

### 从本机添加（两种模式）

- **复制到平台**（默认）：权重复制到 `data/models/imported/`，原文件删了也不影响。
- **仅登记原路径**：不占额外空间，但原文件被移动/删除后模型失效（表格会标 ⚠）。

支持格式：`.pt` `.pth` `.onnx` `.engine` `.torchscript` `.mlmodel` `.tflite`。
`.pt` 能自动读出类别名与任务类型；其它格式留空，可添加后手动补。

### 训练时用仓库模型作为起点

训练页「基础权重来源」三选一：

1. **内置模型** — 从官方预训练权重开始（默认）
2. **模型仓库** — 选已有模型继续训练（增量数据/继续收敛）
3. **本机权重文件** — 直接填本机 `.pt` 路径

> ⚠ 若所选模型的类别数与当前数据集不一致，平台会提示「将重建分类头」。
> 这仍能训练（部分迁移学习），但如果想保留原有识别能力，请保证类别数一致、
> 且类别顺序（data.yaml 的 names）相同。

### 推理验证

推理页统一从仓库选模型，三种验证方式：

- **上传图片**：即时检测，返回画框图 + 每个目标的类别/置信度
- **用数据集图片验证**：从数据集里挑图，检查模型在该图上的表现
- **批量验证**：在整个数据集上跑前 N 张，统计总检出数、无检出图片数、平均推理耗时

## 算力说明（重要）

当前这台机器（Ryzen 7 8845H，无 NVIDIA 独显）**只能用 CPU 训练**：

- 推荐配置：`yolo11n` + `imgsz 416~480` + 图片 ≤ 1000 张，几十 epoch 可接受；
- 大数据集/大模型请迁移到 GPU 机器：拷贝 `yolo-platform` 目录 → `pip install -r requirements.txt`（GPU 机器换成 CUDA 版 torch）→ 训练任务里设备选 `GPU 0` 即可，平台代码零修改。

## 网络说明

首次使用某个基础模型时需要下载预训练权重（yolo11n ≈ 5.4 MB）。平台已内置下载回退链：
**ultralytics 官方(GitHub) → hf-mirror.com 镜像**，国内直连 GitHub 超时也能自动拿到权重，
缓存位置 `data/models/pretrained/`。若全部失败，手动把 `.pt` 放进该目录即可离线训练。
（本机上 yolo11n / yolo11s 已预下载完成，可直接开始训练。）

## 常见操作

- **续训**：任务列表点「续训」，自动从该任务 `weights/last.pt` 恢复。
- **服务重启后任务显示"已中断"**：属正常（训练是子进程，服务重启会清理孤儿任务），直接续训即可。
- **删除任务**：连同其 `data/runs/<task_id>` 产物一起删除。
- **备份数据集**：数据集卡片「导出zip」，之后可原样再导入。
